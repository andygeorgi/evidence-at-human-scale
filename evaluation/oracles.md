# Evaluation oracles

[← Evaluation guide](README.md) · [Catalogue](catalogue/README.md) · [Human-outcome evaluation](human-outcome-evaluation.md)

Each of the twelve evaluation tests, EV01 to EV12, is a set of synthetic fixtures. A fixture has fixed inputs, an expected oracle, a metric and a gate. This page states what each test would have to show if it were run against an implementation. It describes measurements, and none has been taken: there is no implementation to take them against, so every test and fixture is NOT ASSESSED (see the [status words](README.md#status-words)).

The [catalogue](catalogue/README.md) holds the same tests and fixtures as JSON and CSV, together with the input definition and perturbation of each fixture, which this page leaves out. The tables below are generated from it.

## Metrics, denominators and gates

| Metric | Numerator / denominator |
|---|---|
| Evidence-link validity | Valid versioned claim links / emitted evidence claims |
| Fidelity | Faithful claim, scope, unit and type instances / assessed instances |
| Critical retention | Retained critical items / gold critical items |
| Conflict and gap coverage | Represented material conflicts and gaps / gold expected items |
| Missingness | Correct assignments / assessed assignments |
| Reproducibility | Reproducible outputs / fixed-input cases |
| Prohibited events | Raw counts and event counts / evaluated adversarial opportunities, for unauthorised disclosure, unauthorised execution, type promotion and blind unknown retries |
| Budget conformance | Tasks within configured limits / evaluated tasks, with complete or partial scope labels |
| Freshness conformance | Compliant freshness-dependent serves or actions / all evaluated such serves or actions |

A `ratio 1` gate requires every assessed case to come out as prescribed (100%), over a denominator that was declared before scoring and is greater than zero. A `zero 0` gate requires no prohibited event, counted only over adversarial opportunities that were attempted. Zero events over zero attempts is NOT ASSESSED, not a pass, and so is any empty or unlabelled denominator. A result would be reported with its raw counts, its denominators and its uncertainty. The gates are targets for finite synthetic fixtures, not guarantees about production.

## Ownership

Each test needs an accountable owner before it can be run, and none is assigned here. The usual split: source and domain owners own fidelity and rules; lifecycle and selection owners own lineage, conflict and missingness; access and security owners own disclosure, revocation and injection; obligation and operations owners own continuity; executor and target owners own races and outcomes. These are roles, not named people.
